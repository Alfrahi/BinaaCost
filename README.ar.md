# بناء كوست (BinaaCost) 🏗️


[![الترخيص](https://img.shields.io/badge/الترخيص-Apache_2.0-blue.svg)](LICENSE)
[![Vite](https://img.shields.io/badge/مبني_باستخدام-Vite-646CFF.svg)](https://vitejs.dev/)
[![React](https://img.shields.io/badge/React-18.3.1-61DAFB.svg?logo=react)](https://reactjs.org/)
[![PocketBase](https://img.shields.io/badge/الخادم-PocketBase%200.28.0-4285F4.svg)](https://pocketbase.io/)
[![TypeScript](https://img.shields.io/badge/TypeScript-5.9.3-3178C6.svg?logo=typescript)](https://www.typescriptlang.org/)

منصة ويب متكاملة ومتقدمة لحساب تكاليف المشاريع الإنشائية، إعداد الميزانيات، إنشاء عروض الأسعار والمقترحات، ونمذجة المخاطر المالية للمهندسين والمقاولين. تم بناء النظام بالاعتماد على **React 18** و **TypeScript** و **Tailwind CSS** مع خادم وقاعدة بيانات **PocketBase**، ليقدم حسابات مالية بالغة الدقة (مطابقة للسنت والهللة)، واجهة ثنائية اللغة تدعم الاتجاهين (RTL/LTR) بالكامل، إمكانية العمل دون اتصال بالإنترنت (Offline-First PWA)، مكتبات تكاليف بارامترية، ومشاركة آمنة للمشاريع مع العملاء وأصحاب المصلحة.

---

## المميزات الرئيسية

- **إدارة المشاريع الإنشائية**: إنشاء، تعديل، نسخ، وأرشفة المشاريع، مع إدارة موقع المشروع، الجدول الزمني، المساحة، وتفكيك هيكل العمل (WBS).
- **تفصيل دقيق للتكاليف**: تقدير بارامتري مفصل عبر خمسة تصنيفات رئيسية:
  - **المواد (Materials)**: الكميات، الوحدات، أسعار الوحدات، بيانات الموردين، وتوزيع المجموعات.
  - **العمالة (Labor)**: المهن والتخصصات، حجم الأطقم، الأجور اليومية، أيام العمل بالموقع، وحساب إجمالي التكلفة آلياً.
  - **المعدات (Equipment)**: التبديل بين التأجير والشراء، أسعار الفترات، المدة، ومخصصات الوقود والصيانة.
  - **التكاليف الإضافية (Additional Costs)**: بنود التكلفة الإجمالية (Lump-sum) مثل التراخيص، التأمين، الاختبارات الهندسية، والمرافق.
  - **سجل المخاطر (Risk Register)**: تقييم نوعي للمخاطر (منخفض، متوسط، مرتفع) مع احتساب آلي للقيمة المالية المتوقعة لاحتياطي الطوارئ.
- **محرك الحسابات المالية الدقيق**: عمليات حسابية عشرية دقيقة خالية من أخطاء التقريب لحساب التكاليف المباشرة، معاملات الموقع الجغرافي، التكاليف غير المباشرة (Overhead)، احتياطي الطوارئ (ثابت، مستند للمخاطر، أو مدمج)، هامش الربح، سعر العطاء النهائي، الضرائب، ونسب الهامش الإجمالي.
- **مكتبة التكاليف البارامترية**:
  - **قواعد بيانات التكلفة**: قواعد بيانات تعتمد معيار CSI MasterFormat مع معاملات المدن والمواقع واستيراد ملفات CSV بكميات كبيرة.
  - **التراكيب الإنشائية (Assemblies)**: تراكيب ومجموعات إنشائية جاهزة عبر مهن متعددة مع معاملات التعديل والحجم.
  - **المكتبات المخصصة**: مكتبات أسعار وحدات خاصة للمستخدم للمواد القياسية والعمالة والمعدات مع مزامنة مانعة للتكرار.
- **محاكاة السيناريوهات وتحليل الحساسية**: نمذجة حساسية من جانب الخادم لمحاكاة آثار التضخم، تقلبات أجور العمالة، التأخير الزمني، وتحقق المخاطر دون التعديل على بيانات المشروع الأصلية.
- **عروض الأسعار والتقارير التنفيذية**:
  - توليد عروض أسعار رسمية للعملاء تشمل الملخص التنفيذي، الشروط والأحكام، وخانات التوقيع.
  - تنبيهات مراقبة الجودة لاكتشاف البنود غير المكتملة أو غير المسعرة قبل الإرسال.
  - تصدير تقارير PDF عالية الدقة ومجهزة للطباعة بالنمط الفاتح عبر المتصفح مباشرة.
- **إدارة الإصدارات وسجل التعديلات (Audit Trail)**:
  - لقطات تاريخية للمشروع في أي نقطة زمنية مع تجميد الملخص المالي.
  - مقارنة جنبًا إلى جنب بين الإصدارات مع حساب الفوارق المالية بنداً ببند.
  - فحص بصري ثلاثي (Three-way diffing) وحل التعارضات قبل استعادة أي إصدار سابق.
  - قفل الإصدارات المعتمدة لمنع تعديلها أو حذفها بطريق الخطأ.
- **المشاركة والتعاون الجماعي**:
  - تعاون داخلي لفريق العمل بأدوار وصلاحيات محددة (`مشاهد` و `محرر`).
  - روابط مشاركة خارجية آمنة تعتمد رموز تشفير بطول 48 خانة مع تاريخ انتهاء إلزامي وحماية اختيارية بكلمة مرور.
  - صفحة عرض عامة للعملاء تحسب الإجماليات عبر الخادم وتحجب سجلات المخاطر الحساسة.
- **بنية العمل دون اتصال (Offline-First PWA)**:
  - تطبيق ويب تقدمي قابل للتثبيت على الأجهزة مع تخزين مؤقت للخدمات عبر Workbox.
  - طابور تعديلات محلي عبر LocalForage مع إعادة إرسال ومزامنة تلقائية فور عودة الاتصال.
  - حماية العمليات المتكررة عبر معرفات فريدة (`client_mutation_id`).
  - درج مخصص لإدارة العمليات التي تعذر مزامنتها ومعالجتها.
- **لوحة إدارة النظام (Admin Suite)**:
  - إدارة المستخدمين (إنشاء، استعراض، تعديل، حذف، وتعيين صلاحيات `مستخدم` أو `مدير عام`).
  - إدارة شاملة للمشاريع مع إمكانية نقل ملكية المشاريع بين المستخدمين.
  - تخصيص القوائم المنسدلة ثنائية اللغة للوحدات، والتصنيفات، والاحتمالات.
  - سجل تدقيق ومراقبة شامل يتتبع التعديلات عبر 22 جدولاً في قاعدة البيانات.
- **دعم ثنائي اللغة والاتجاه (i18n)**:
  - واجهة عربية كاملة من اليمين لليسار (RTL) وواجهة إنجليزية (LTR).
  - خط عربي مخصص وواضح (`Noto Sans Arabic`).
  - اختبارات آلية للتحقق من تطابق المفاتيح والترجمات بين اللغتين.

## التشغيل والتثبيت (Getting Started)

<div dir="rtl">

### المتطلبات الأساسية
- **Node.js**: إصدار `v20.x` أو أحدث.
- **pnpm**: إصدار `v9.x` أو أحدث (`pnpm` مطلوب إلزاميًا).
- **PocketBase**: ملف تشغيل تنفيذي جاهز في مجلد `pocketbase/pocketbase` (لنواة Linux x86_64) أو يمكن تنزيله من [pocketbase.io](https://pocketbase.io).

### 1. تثبيت الحزم والاعتماديات
</div>

```bash
pnpm install
```

<div dir="rtl">

### 2. إعداد متغيرات البيئة
انسخ ملف الإعدادات النموذجي:
</div>

```bash
cp .env.example .env
```

<div dir="rtl">

تأكد من أن ملف `.env` يحتوي على:
</div>

```bash
VITE_POCKETBASE_URL=/
```

<div dir="rtl">

### 3. النشر للإنتاج عبر Docker (موصى به)
يتضمن المشروع إعدادات نشر إنتاجي متكاملة ومؤتمتة باستخدام Docker Compose:
</div>

```bash
docker compose up -d --build
```

<div dir="rtl">
يقوم هذا الأمر بتشغيل خادم PocketBase (مع ربط مجلد البيانات بـ `./pb_data`) وخادم Caddy العكسي لتشغيل بروتوكول HTTPS عبر المنفذ 443.

### 4. التشغيل في بيئة التطوير المحلية
إذا كنت تفضل التشغيل المحلي المباشر دون Docker:

في نافذة الطرفية الأولى (تشغيل قاعدة البيانات والخادم):
</div>

```bash
cd pocketbase
./pocketbase serve --dev
```

<div dir="rtl">
في نافذة الطرفية الثانية (تشغيل خادم الواجهة الأمامية):
</div>

```bash
pnpm dev
```

<div dir="rtl">
سيكون التطبيق متاحاً على المتصفح عبر العنوان: **`http://127.0.0.1:8080`**.

## الأوامر المتاحة

تُنفذ كافة الأوامر والسكربتات عبر مدير الحزم `pnpm`:

| الأمر | الوصف |
| :--- | :--- |
| `pnpm dev` | تشغيل خادم التطوير مع التحديث السريع والمباشر للكود (HMR) على المنفذ 8080 |
| `pnpm build` | التحقق من صحة أنواع TypeScript وبناء الحزمة الإنتاجية في مجلد `dist/` |
| `pnpm preview` | تشغيل النسخة الإنتاجية محلياً للمعاينة والتحقق |
| `pnpm typecheck` | تشغيل مدقق لغة TypeScript على كامل ملفات المشروع |
| `pnpm lint` | فحص الشيفرة المصدرية باستخدام ESLint بدون أي تحذيرات مسموحة (`--max-warnings 0`) |
| `pnpm lint:fix` | فحص وتصحيح أخطاء التنسيق تلقائياً عبر ESLint |
| `pnpm test` | تشغيل اختبارات Vitest التفاعلية بوضع المراقبة |
| `pnpm test run` | تشغيل جميع ملفات اختبارات الوحدة والتكامل (64 ملف اختبار) دفعة واحدة |
| `pnpm coverage` | تشغيل الاختبارات وإصدار تقرير تفصيلي بنسبة تغطية الكود |
| `pnpm e2e` | تشغيل اختبارات المتصفح الشاملة (E2E) عبر Chromium و Firefox و WebKit باستخدام Playwright |

## الاختبارات وجودة الكود

يحافظ المشروع على تغطية اختبارات شاملة تشمل اختبارات الوحدة والتكامل والاختبارات الشاملة (E2E):

</div>

```bash
# تشغيل فحص الأنواع والتنسيق واختبارات الوحدة
pnpm typecheck && pnpm lint && pnpm test run

# تشغيل اختبارات المتصفح الشاملة (يتطلب تشغيل PocketBase على منفذ 8090)
pnpm e2e
```

للمزيد من تفاصيل وإجراءات الاختبارات، راجع [دليل الاختبارات (docs/testing.md)](docs/testing.md).

## المساهمة والتطوير

نرحب بمساهمتكم في تطوير **بناء كوست (BinaaCost)**. يُرجى مراجعة [دليل المساهمة (CONTRIBUTING.md)](CONTRIBUTING.md) للاطلاع على معايير كتابة الكود، إجراءات ترحيل قاعدة البيانات، متطلبات الترجمة، وإرشادات طلبات السحب (Pull Requests).

### التحقق المحلي والتوافق مع CI

قبل تقديم طلب سحب (PR)، تأكد من اجتياز الشيفرة لكافة فحوصات التكامل المستمر:

- **فحص التحقق الشامل**: `pnpm check` (يشمل فحص الأنواع، التنسيق، واختبارات الوحدة).
- **اختبارات المتصفح الشاملة**: تشغيل خادم PocketBase (`./pocketbase serve --dev`) ثم تشغيل `pnpm e2e`.
